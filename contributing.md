# Contribution Guidelines

Thanks for helping students save money! This list stays useful only if every entry is **real, current and verifiable**, so please follow these rules.

## What belongs here

- The offer is **free** for students, or a large discount (50%+) for the [discounts section](readme.md#not-free-but-big-discounts).
- It's an **official offer** from the company or a program like the GitHub Student Developer Pack. No coupon sites, referral links or "free trial for everyone" offers.
- It's useful to students who build, design, research or learn.

## Adding an offer

1. Add one line to the right section, in this format:

   ```markdown
   - [Name](https://official-link) - What students get, how long it lasts, and who qualifies. 🎒 📧 🔁
   ```

2. Link to the **official offer page**, not a blog post about it.
3. Include the important fine print: duration, age limits, regions, verification method.
4. Add the tags that apply (see the legend at the top of the readme).
5. Start the description with a capital letter and end it with a period (before the tags).
6. In your pull request, paste the official source that shows the offer is active today.

## Reporting a dead or changed offer

[Open an issue](../../issues/new/choose) using the "Offer ended or changed" template, or send a pull request that moves the entry to the [Recently ended](readme.md#recently-ended) table.

## Pull request checklist

- One offer per pull request (so it's easy to review).
- Search the list first so you don't add a duplicate.
- No affiliate or referral links.
- The link checker must pass.

By contributing, you agree that your contribution is released under [CC0](license) and that you'll follow the [Code of Conduct](code-of-conduct.md).
